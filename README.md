**Newme Automation**

Playwright automation testing project for the Newme Asia web application.

**Project Overview**

This project contains automated test scripts created using Playwright with JavaScript to validate important functionalities of the Newme Asia website.

The project focuses on basic functional and UI automation testing from a user's perspective.

Defect Identified During Testing

While testing the search functionality manually, an issue was observed where entering an irrelevant/random search keyword still displayed products instead of showing an appropriate "No products found" message.

This observation was considered while creating the automation test scenarios.
